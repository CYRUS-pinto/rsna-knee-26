# CV Framework Verification Suite (`test_cv_framework.py`)

## 1. Overview
`test_cv_framework.py` is an automated, dependency-free test suite verifying the mathematical correctness and data integrity of the cross-validation partition generated by [`validation/cv_framework.py`](file:///c:/Users/Cyrus/Downloads/rsna%20knee%20fip/validation/cv_framework.py).

---

## 2. Tested Invariants & Assertions

### Invariant 1: Complete Study Coverage
- Total unique studies in partition must equal total studies in input table ($N=4,407$).
- Every study must be assigned exactly one fold $\in \{0, 1, 2, 3, 4\}$.
- No null or unassigned fold values (`assignment.isna().sum() == 0`).

### Invariant 2: Gold Anchor Stratification
- All 58 Gold studies must be present.
- Each fold must receive between 11 and 12 Gold studies ($\max(\text{gold\_counts}) - \min(\text{gold\_counts}) \le 1$).

### Invariant 3: Disjoint Folds (Zero Data Leakage)
- For every pair of folds $(j, k)$ where $j \ne k$:
$$\text{Studies}_{\text{fold } j} \cap \text{Studies}_{\text{fold } k} = \emptyset$$
This guarantees 0% cross-fold contamination during evaluation.
